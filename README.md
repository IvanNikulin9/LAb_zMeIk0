# Лабораторная работа 1: Игра «Змейка»

## Описание
Консольная игра «Змейка», написанная на Python. Проект реализует классическую механику: движение по полю, поедание еды, рост змейки, увеличение счета. Предусмотрено завершение игры при столкновении со стеной или собственным хвостом, а также режим паузы и повторной игры. Проект имеет строгую типизацию (`mypy --strict`), отформатирован (`ruff format`) и покрыт тестами (`pytest`).

## Структура проекта
* `src/snake.py` — логика змейки (класс `Snake`)
* `src/game.py` — игровое поле, еда, счет (класс `Game`)
* `main.py` — точка входа (CLI и отрисовка в терминале)
* `tests/` — автоматические тесты (`pytest`)
* `.github/workflows/ci.yml` — настройка CI (GitHub Actions)

## Как запустить игру
Убедитесь, что у вас установлен [uv](https://astral.sh/uv).
В терминале выполните:
```bash
uv run python main.py --width 20 --height 20 --speed 8
